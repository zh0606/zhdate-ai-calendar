# Product Requirement Document

## 1. Background

Traditional calendar applications require users to manually fill in event names, dates and reminders.

This process is repetitive and inefficient.

Large language models make it possible to create schedules directly from natural language.

Therefore, zhdate aims to simplify schedule management through AI.

---

## 2. Product Goal

Allow users to create calendar events using natural language.

Reduce manual operations.

Provide AI-generated reminder suggestions.

---

## 3. Target Users

Primary users include:

- University students
- Young professionals
- Users with busy schedules

---

## 4. User Scenario

Example:

User says:

"下周二下午两点开组会"

The system automatically extracts:

- Event title
- Date
- Time

and displays it in the calendar.

---

## 5. Core Functions

### AI Schedule Creation

Convert natural language into structured events.

### Calendar Display

Display monthly schedules.

### AI Reminder

Generate personalized reminder messages.

### Task Management

View today's schedule.
